A

Como sustantivo se puede usar en este contexto:

  1. Para nombrar la primera letra del alfabeto, y la traducción es la letra A.

    Please write a capital A on the first line. (Por favor, escribe una A mayúscula en la primera línea.)

B

Como sustantivo se puede usar en este contexto:

  1. Para nombrar la segunda letra del alfabeto, y la traducción es la letra B.

    My name starts with a capital B. (Mi nombre empieza con una B mayúscula.)

C

Como sustantivo se puede usar en este contexto:

  1. Para nombrar la tercera letra del alfabeto, y la traducción es la letra C.

    The sign on the door has a red C painted on it. (El letrero de la puerta tiene una C roja pintada.)

D

Como sustantivo se puede usar en este contexto:

  1. Para nombrar la cuarta letra del alfabeto, y la traducción es la letra D.

    My brother's name starts with a capital D. (El nombre de mi hermano empieza con una D mayúscula.)

Drink

Como sustantivo se usa en estos contextos:

  1. Para nombrar un líquido que se bebe, y la traducción es bebida.

    Would you like a drink? (¿Quieres una bebida?)

  2. Para hablar de una bebida alcohólica, y la traducción es trago.

    Let's go out for a drink. (Salgamos a tomar un trago.)
